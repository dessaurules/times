Layout — Rechter Bereich: 3 Ansätze

Das Problem: max-w-5xl in AppLayout begrenzt den Inhalt auf 896px — rechts bleibt grauer Leerraum. Klick auf deinen bevorzugten Ansatz.

A

Full Width — max-w-5xl entfernen

Inhalt füllt die gesamte verfügbare Breite. Einfachste Lösung, 1 Zeile Code.

B

Rechte Seitenleiste — kontextuell, ~260px

Feste Seitenleiste rechts mit seitenspezifischen Infos: offene Anträge, heutige Abwesenheiten, Schnellzugriff.

C

Hybrid — Full Width + lokale max-width für Formulare

Keine globale Breitenbegrenzung. Datenstarke Seiten (Dienstplan, Abwesenheiten) nutzen volle Breite. Formular-Seiten (Einstellungen) begrenzen sich selbst lokal.

Option B (Seitenleiste) wäre nur dann sinnvoll, wenn du wirklich dauerhaft sichtbare Infos rechts brauchst — aber die wichtigsten Quickinfos (Abwesenheiten, eingestempelt) hast du bereits im Dashboard.
